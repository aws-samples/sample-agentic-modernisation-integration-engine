# Roadmap

> **This project delivers specs, not code.** Each phase produces requirements, design, and a task plan that an AI coding agent (like Kiro) can use to generate the full application.

## Phase 1 — Code Analysis & Transformation

The foundation: deterministic code analysis, AI documentation, and Java transformation.

| Feature | Status |
|---------|--------|
| Multi-language code parsing (Java, Python, JS, C#, C, Ab Initio) | ✅ Complete |
| Dependency extraction, architecture diagrams, and vulnerability scanning | ✅ Complete |
| AI documentation generation with quality scoring | ✅ Complete |
| ATX code assessment with real-time SSE streaming | ✅ Complete |
| ATX Java transformation (diff preview + download + PR) | ✅ Complete |
| React frontend with analysis dashboard and visualization | ✅ Complete |
| Three-mode authentication (disabled / local JWT / Cognito) | ✅ Complete |

## Phase 2 — Architecture Design Generation

AI-powered To-Be architecture design: target-state diagrams, migration strategies, and architecture decision records from an analysed codebase.

## Phase 3 — Migration & Modernisation Pathways

Guided step-by-step journeys for common application patterns — taking users from legacy state through each stage of migration and modernisation to completion.

## Phase 4 — UI Test Generation

Autonomous test creation — AI agents analyse your application, generate meaningful test scenarios, produce runnable Playwright scripts, and execute them against your UI.

## Future Ideas

- Security fix generation (AI-assisted vulnerability remediation)
- Additional language parsers
- Cost tracking and usage analytics
